# 🎬 Proyecto StreamFlix — SQL Bootcamp Week 1

Base de datos relacional de un catálogo de streaming construida con MySQL.
Incluye 15 películas reales con 12 columnas: título, género, año, duración, idioma, director, país, clasificación, puntuación, precio de alquiler, disponibilidad y fecha de añadido.

## 🛠️ Tecnologías
MySQL 8.0 · MySQL Workbench

## 📁 Contenido
- `entrega_semana1.sql` — Script completo: creación de base de datos, tabla e inserción de datos + 11 queries de catálogo y 3 retos resueltos

## 🧠 Conceptos aplicados
`CREATE DATABASE` · `CREATE TABLE` · `INSERT INTO` · `SELECT` · `WHERE` · `ORDER BY` · tipos de datos · restricciones `NOT NULL`
